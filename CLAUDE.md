# CLAUDE.md

Правила работы с Claude Code в этом репозитории.

## Цель проекта

Демо-кейс портфолио: агент-оркестратор заявок. Заявка из Telegram-webhook или веб-формы →
LLM-классификация (тип / срочность / извлечение полей: имя, контакт, суть) → запись в реестр
(SQLite) → уведомление ответственному.

Позиционирование автора: **backend-разработчик, встраивающий AI-агентов в реальную инфраструктуру**.
Проект — доказательство этого позиционирования: рабочий контур, а не абстрактная «нейросеть».

Статус: рабочий инкремент готов (демо), развитие — по `docs/plan.md`.

## Стек

- **Python / FastAPI** — сервис целиком: приём (webhook + форма), классификация, реестр, уведомления
- **OpenRouter API** — основная бесплатная LLM-модель (`nvidia/nemotron-3-super-120b-a12b:free`);
  резерв — GLM API (`glm-4-flash`); последний fallback — regex-правила
- **SQLite** — реестр заявок + таблица уведомлений (слот под Google Sheets — через env)
- **Telegram Bot API** — приём заявок и уведомления (пустой токен = режим мока: лог + лента)
- **Docker Compose** — запуск одной командой; n8n — опция (profile `n8n`)

## Правила

1. **Секреты — только в `.env`.** Ключи, токены, пути к credentials не коммитим ни в код, ни в docs,
   не выводим в логи и stdout. В репозитории — только `.env.example` с пустыми значениями.
2. **Git-identity локальная.** В этом репо: `agenticflow64` / `93826006+agenticflow64@users.noreply.github.com`
   (задана через локальный `git config`, без `--global`). Не менять и не заменять глобальным аккаунтом.
3. **Пуш только в `agenticflow64/lead-orchestrator`.** Никаких других remote, никакого force-push в main
   после того как история ушла на GitHub.
4. **Ничего из основного места работы.** Ни кода, ни названий внутренних систем, ни форматов данных,
   ни текстов заявок из реальных рабочих каналов. Только вымышленные демо-данные.
5. **Цифры помечать «демо».** Любые метрики в README и кейсе — из локальных замеров (`scripts/eval_dataset.py`),
   с пометкой «демо». Не выдумывать числа.
6. Язык — русский; UI и README на русском, код и идентификаторы — на английском.
7. **Коммиты — без Co-Authored-By и без упоминаний ИИ/агентов**, как от владельца репозитория.
