# CLAUDE.md

Правила работы с Claude Code в этом репозитории.

## Цель проекта

Демо-кейс портфолио: агент-оркестратор заявок. Telegram-бот принимает заявку → LLM-классификация
(тип / срочность / извлечение полей: имя, контакт, суть) → запись в Google Sheets (или таблицу-заглушку)
→ уведомление ответственному.

Позиционирование автора: **backend-разработчик, встраивающий AI-агентов в реальную инфраструктуру**.
Проект — доказательство этого позиционирования: рабочий контур, а не абстрактная «нейросеть».

Статус: в разработке по вечерам (см. `docs/plan.md`).

## Стек

- n8n — оркестратор workflow (docker-compose, порт 5678), понятен заказчикам
- Python — функция классификации на GLM API (OpenAI-совместимый, base URL `https://open.bigmodel.cn/api/paas/v4`)
- Google Sheets API — реестр заявок (демо: таблица-загушка)
- Telegram Bot API — вход заявок, уведомления
- Docker Compose — локальный запуск

Вариант B (по запросу, не реализован): Kafka + Python-микросервис — упомянут в README и `docs/architecture.md`.

## Правила

1. **Секреты — только в `.env`.** Ключи, токены, пути к credentials не коммитим ни в код, ни в docs.
   В репозитории — только `.env.example` с пустыми значениями.
2. **Git-identity локальная.** В этом репо: `agenticflow64` / `93826006+agenticflow64@users.noreply.github.com`
   (задана через локальный `git config`, без `--global`). Не менять и не заменять глобальным аккаунтом.
3. **Пуш только в `agenticflow64/lead-orchestrator`.** Никаких других remote, никакого force-push в main
   после того как история ушла на GitHub.
4. **Ничего из основного места работы.** Ни кода, ни названий внутренних систем, ни форматов данных,
   ни текстов заявок из реальных рабочих каналов. Только вымышленные демо-данные.
5. **Цифры помечать «демо».** Любые метрики в README и кейсе — из локальных замеров, с пометкой
   «в разработке, цифры будут из локальных замеров (демо)», пока замеры не сделаны. Не выдумывать числа.
6. Язык — русский; технические названия (n8n, webhook, Google Sheets, Kafka) — на английском.
7. Коммиты — с последней строкой `Co-Authored-By: Claude Code <noreply@anthropic.com>`.
