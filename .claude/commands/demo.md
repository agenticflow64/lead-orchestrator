Чек-лист:

1. Окружение:
   - [ ] `docker compose ps` — n8n запущен;
   - [ ] workflow активирован (не paused);
   - [ ] `.env` заполнен: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `GLM_API_KEY`;
   - [ ] таблица-реестр открыта, новые строки видны без прокрутки.
2. Репетиция (до записи, прогнать быстро):
   - [ ] заявка №6 из `docs/test-leads.md` → строка в таблице + уведомление «СРОЧНО»;
   - [ ] заявка №2 → тип `price_question`, уведомление без пометки;

   - [ ] засечь время «сообщение → строка в таблице» для каждой — произнести на записи.
3. Запись:
   - [ ] разрешение минимум 1080p, оба окна читаемы на записи;
   - [ ] сценарий и таймкоды — по `docs/demo-script.md`, тексты заявок из буфера обмена;

4. После записи:
   - [ ] проверить, что моменты «строка появилась» и «уведомление пришло» видны на записи;
   - [ ] при пересъёмке — только проблемный фрагмент, не всё;
   - [ ] обновить метрики в README командой `/case-update`.
