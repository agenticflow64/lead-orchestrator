# План по вечерам

Три вечера по 2–3 часа. Цель каждого вечера — рабочий инкремент, который можно показать.

## Вечер 1 — каркас: сервис, приём заявок

- [x] FastAPI-каркас: `docker compose up`, сервис на http://localhost:8000
- [x] Webhook `POST /webhook/telegram` (формат апдейтов Bot API — в прод только подставить токен)
- [x] Веб-форма заявки на дашборде как второй канал

**Результат вечера:** заявка доходит до сервиса из двух каналов.

## Вечер 2 — классификация + реестр + уведомление

- [x] Тип, срочность, извлечение имени / контакта / сути; JSON-выход с валидацией и ретраями
- [x] Реестр SQLite + дашборд: фильтры, статусы new/in_progress/done, экспорт CSV
- [x] Уведомления: Telegram при заданном токене, иначе notifications.log + лента на дашборде
- [x] Фильтр спама: пометка в реестре, без уведомления

**Результат вечера:** полный контур из README работает end-to-end.
