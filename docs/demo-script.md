# Сценарий демо (до 2 минут)

Цель: показать полный контур «сообщение → строка в таблице → уведомление» в реальном времени.
Подготовка: n8n запущен (`docker compose up -d`), таблица-реестр открыта на экране, Telegram с ботом
и чат ответственного — рядом (два окна или split screen).

## Таймкоды

| Время | Что происходит | Что говорить |
|---|---|---|
| 0:00 | Экран: два окна — Telegram (бот) и таблица-реестр. | «Заявки клиентов приходят боту в Telegram. Сейчас отправлю заявку — и покажу, что с ней происходит.» |
| 0:10 | Пишу боту: «Здравствуйте! Меня зовут Ольга, ошибка оплаты на сайте, не списываются деньги, тел. +7 900 123-45-67. Когда исправите?!» | «Реальная по формату заявка: есть имя, контакт, суть — и эмоции.» |
| 0:25 | Ждём (секунды). Показываю таблицу: появилась строка — Ольга, контакт, тип `support`, срочность `high`, суть в одном предложении. | «Секунды спустя заявка уже в реестре: тип и срочность определил LLM-классификатор, поля извлечены из свободного текста.» |
| 0:45 | Показываю чат ответственного: уведомление с пометкой «СРОЧНО». | «Ответственный получил уведомление сразу; срочные — с пометкой, их не потерять в общем потоке.» |
| 1:00 | Пишу вторую заявку: «Сколько стоит интеграция с 1С? Александр, a.petrov@company.ru» | «Вторая заявка — другой тип.» |
| 1:15 | Таблица: новая строка, тип `price_question`, срочность `medium`. Уведомление без пометки «СРОЧНО». | «Вопрос о цене классифицирован иначе и ушёл с другой срочностью — маршрутизация без ручного разбора.» |
| 1:30 | Пишу спам: «КУПИЮ ГОТОВЫЙ БИЗНЕС ПИШИ В ЛС $$$». Таблица: строка со флагом спам, уведомления нет. | «Спам фильтруется: в реестре помечен, ответственного не дёргает.» |
| 1:45 | Итог на экране: workflow в n8n (один экран). | «Весь контур — один workflow в n8n, LLM-логика изолирована в Python-функции. Метрики обработки — в README кейса.» |

## Чек-лист перед записью

- [ ] n8n работает, workflow активен (проверить тестовой заявкой до записи).
- [ ] Таблица-реестр открыта, строки отсортированы по времени (новые сверху/снизу — как удобнее показать).
- [ ] Чат ответственного открыт и виден.
- [ ] Три заявки из сценария скопированы в буфер (чтобы не печатать на камеру).
- [ ] Таймер на экране или секундомер — для честных «секунд до строки в таблице».
- [ ] Метрика времени обработана: разница таймстемпов сообщения и записи — назвать её вслух на 0:25.
