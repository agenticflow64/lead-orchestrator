# Сценарий демо (до 2 минут)

Цель: показать полный контур «сообщение → строка в реестре → уведомление» в реальном времени.
Подготовка: `docker compose up`, дашборд открыт на http://localhost:8000 (браузер ~75% экрана),
рядом — терминал для curl-заявок (или второй канал — веб-форма на самом дашборде).
Telegram не обязателен: без токена уведомления видны в ленте «Последние уведомления» на дашборде.

## Чек-лист перед записью

- [ ] `docker compose up` — сервис отвечает на http://localhost:8000/api/health.
- [ ] `.env` заполнен (`OPENROUTER_API_KEY`); `TELEGRAM_BOT_TOKEN` пуст → режим мока (лента на дашборде).
- [ ] Реестр пуст или почищен (`data/` удалён) — строки демо будут первыми.
- [ ] Три заявки из сценария скопированы в буфер (чтобы не печатать на камеру).
- [ ] Проверить до записи тестовой заявкой: строка появляется, уведомление в ленте.
- [ ] Метрики README — свежие (`scripts/eval_dataset.py`), назвать «~3 секунды end-to-end» вслух на 0:20.
